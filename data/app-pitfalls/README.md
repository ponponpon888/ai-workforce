## idem-002 を自分のリポジトリで見る

`idem-002`（効いていない冪等キー）だけは、対象コードを読むだけで当てられます。

```
node kit/scripts/check-idem-002.mjs --root ../your-app
node kit/scripts/check-idem-002.mjs --root ../your-app --json
```

`--root` の下の `.js` / `.mjs` / `.cjs` を読み、**受信ごとに増えるログ行の id を、配信とともに届く
id より先に選んでいる**冪等キーを報告します。`--root` の中身を import・実行することはなく、
対象側の設定ファイルも読みません。

指摘するのは、1 つの関数の中で次の 3 つがそろったときだけです。名前だけでは判定しません。

1. `.insert(...).select('id')` から束縛された行 id（payload に `id` が無く、配信ごとに新しい）
2. その行 id を `||` / `??` の**先頭**で選び、配信由来の id を後ろに置く式
3. その値が実際に `idempotency_key` へ渡っていること

終了コード: `0` 読めて該当なし / `1` 該当あり / `2` 呼び出し誤り / `3` 不完全（読める候補が
0 件、または読めなかった候補がある）。`3` を `0` と分けているのは、「見ていない」と
「見たが何も無かった」が別の答えだからです。

このレコードの `detection.checkable` は `false` のままです。当てる先は読む人のアプリであって
このリポジトリではなく、`lint-pitfalls` は自分のルートの決まったパスしか読みません。
