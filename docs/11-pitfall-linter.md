# 11. 落とし穴の静的検査

記録の形を検査する `validate-pitfalls.mjs` に加え、`lint-pitfalls.mjs` は
インデックスの `checks` を対象ファイルに適用します。Node.js 22以上、追加依存なしです。

20以上ではなく22以上なのは、**Node 20 が 2026-04-30 にサポート終了している**ためです
（[nodejs/Release](https://github.com/nodejs/Release) の schedule.json）。22 は修正が
続いている一番古い系列で、2027-04-30 までです。CI も同じ 22 で回しています。
「20以上」と書いたまま CI も20で回していたので、**サポートの切れたランタイムで全部が緑**
という状態が5ヶ月続いていました。

```powershell
node kit/scripts/lint-pitfalls.mjs
node kit/scripts/lint-pitfalls.mjs --json
node kit/scripts/lint-pitfalls.mjs --root "C:/work/ai-workforce" --json
node kit/scripts/test-lint-pitfalls.mjs
```

既定のルートはスクリプトが置かれたリポジトリです。`--root` を指定すると、
そのルートの `data/pitfalls.index.json` と対象ファイルを読みます。
書き込み、修正、コマンド実行、ネットワークアクセスは行いません。

| 検査種別 | 判定対象 |
|---|---|
| `file-content` | UTF-8テキスト全体の、大文字小文字を区別する文字列の部分一致 |
| `settings-json` | JSONを解析した後の `permissions.allow` / `ask` / `deny` 配列内の文字列の部分一致 |
| その他（`exit-code` / `manual` を含む） | 判定不能。実行はしない |

`pattern` は正規表現ではありません。`expect: present` は一致があれば合格、
`absent` は一致がなければ合格です。設定の説明文や他のキーは権限検査の対象外です。
`permissions` オブジェクトは必須ですが、省略された権限配列は空として扱います。
JSON全体の設定スキーマを検証する機能ではありません。

| 終了コード | 意味 |
|---|---|
| 0 | 定義された全チェックが合格 |
| 1 | 違反が1件以上。判定不能もあれば結果に残す |
| 2 | 違反はないが判定不能、または入力・引数が不正 |

ファイル欠落、不正JSON、未対応の検査種別は合格にしません。
壊れたUTF-8やNULを含むテキスト（UTF-16の典型例を含む）も判定不能です。
UTF-8の先頭BOMは読み取り時に除去します。インデックスにも同じ文字コード検査を適用します。
文字コードの自動判別・変換は行わないため、対象ファイルはUTF-8で保存してください。
空のチェック一覧、未知のインデックス版、ID重複、レコードとチェックの対応漏れも判定不能です。
対象はルート内の2 MiB以下の通常ファイルに限定し、絶対パス・親参照・
ルート外を指すシンボリックリンクを拒否します。読み取り中に別プロセスが
ファイルやリンクを変更する環境に対する隔離境界ではありません。

JSON出力には件数、各結果のID・理由・確度・`stale_risk`を含みます。
現在は12レコード中5件を検査し、7件は自動検査対象外として別に数えます。
合格してもレコードの確度・対処状況を更新しません。コメント中に文字列が
残っているだけでも `file-content` は合格し得ます。フックの動作やClaude Codeの
権限判定の正しさ、安全性を保証するものではなく、動作テストは引き続き必要です。

ローカル実行はインデックスの鮮度を検証しません。レコード変更時はバリデータを
実行してインデックスを再生成してください。既存のCI `pitfalls` ジョブは
レコード検証・インデックス差分検査に加え、このテストと静的検査を実行します。
