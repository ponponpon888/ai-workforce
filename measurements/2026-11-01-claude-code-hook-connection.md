## ケース別判定

### 1. `pwd` — 本体接続を確認（独立観測として記録）

- 根拠: Bash 向け3フック（sql / secrets / destructive）が各2回、すべて exit 0（**初回3ケースの範囲に対する集計**）。PreToolUse が Bash 呼出しに対して実際に起動し、親プロセスへ終了コードを返している。

### 2. `cat .env` — フック遮断は未確認（遮断の事実なし）

## この試験で不足している証拠（次回の計測設計向け）

5. `guard-config.mjs` が Bash マッチャに含まれていない点の仕様確認（意図的かどうか）。
6. **Read 系ツールがフック対象外**であること。Bash 以外の経路はログに痕跡が残らないため、「どのツールを通ったか」をログだけで判定できない。
